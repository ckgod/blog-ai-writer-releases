# 블로그 AI 글쓰기 — 설치 파일

네이버 블로그 글쓰기 화면에서 올린 사진을 읽고, 내 블로그 말투로 사진마다 초안을 써 주는 크롬 확장입니다.
글은 각자의 AI 계정(Claude 구독 또는 구글 계정)으로 만듭니다.

이 저장소에는 설치 파일만 있습니다. 소스 코드는 공개하지 않습니다.

## 설치·업데이트

**Windows**: [BlogAiWriter-Setup.exe](https://github.com/ckgod/blog-ai-writer-releases/releases/latest/download/BlogAiWriter-Setup.exe) 를 받아 실행합니다.

**macOS**: 터미널(응용 프로그램 → 유틸리티 → 터미널)에 아래 한 줄을 붙여 넣고 Enter 를 누릅니다.

```
curl -fsSL https://github.com/ckgod/blog-ai-writer-releases/releases/latest/download/mac-setup.sh | bash
```

업데이트도 같은 방법으로 한 뒤, 크롬 주소창에 `chrome://extensions` 를 열어 이 확장 카드의 새로고침(↻)을 누릅니다.

지난 버전은 [Releases](https://github.com/ckgod/blog-ai-writer-releases/releases) 에 있습니다.
